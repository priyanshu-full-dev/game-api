# game-api

A modern Node.js API built with TypeScript, Express, and Axios for fetching live sports match data.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Copy the environment variables template and configure it:
   ```bash
   cp .env.example .env
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
